# Browser test plan: product selection, research context, generation states, evidence

**Prepared, not run.** It needs a browser runner (Playwright) that is not a dependency of this project, and a signed-in session. Nothing here may be pointed at a live tenant or a provider: every backend call is answered by the test (route interception), so no research, no search and no database is involved.

Run (after an approved `npm i -D @playwright/test`, on a local build): `npx playwright test e2e/signals-generation.spec.ts`

## Checks
1. **Product selection**: `/signals` shows the Product dropdown; choosing another product changes the "Will use:" line; nothing is generated by choosing.
2. **Backend-provided context**: the line shows the ICP name, version, source and regions exactly as `GET /api/portfolio/products/<key>` returns them in `research_context`.
3. **Missing-field warnings**: with `warnings` in the response, the amber list shows them and links to `/portfolio/<key>?tab=icp` (no 404); with `icp: null` the page says there is no active ICP and Generate Signals still only calls the backend, which refuses.
4. **Generation states**: idle (button enabled), running (button disabled and labelled "Generating...", a second click sends no second request), partial ("Finished with limits"), failed (error text and Retry, no success), `completion: incomplete` ("did not finish", not "nothing qualified"), completed with zero ("no opportunity had enough evidence" plus reasons).
5. **Dates and pages**: today and the two days before are offered; an older date from the calendar loads that day; five signals per page; Previous/Next; a filter change returns to page 1; a day with no run shows the empty state.
6. **Evidence display**: a signal opened with "Evidence and details" shows the source link, the publication date, "The full page was read" only when `read_as` is `page_text`, and "not verified on the page itself" when `quote_verified` is false.

## Skeleton (Playwright)
```ts
import { test, expect } from '@playwright/test'

test('research context and missing-field warning', async ({ page }) => {
  await page.route('**/api/portfolio/products', (r) => r.fulfill({ json: { status: 1, data: { products: [/* fixture */], company_profile: null } } }))
  await page.route('**/api/portfolio/products/g2g', (r) => r.fulfill({ json: { status: 1, data: { research_context: {
    product: { key: 'g2g', label: 'G2G', custom: false }, icp: { source: 'database', profile_id: 1, name: 'G2G ICP', version: 3, regions: ['Gujarat'], saved: true },
    product_fields: [], icp_fields: [], kept_for_people: [], offer_count: 2, warnings: ['The ICP does not say a geography.'] } } } }))
  await page.goto('/signals?product=g2g')
  await expect(page.getByText('Will use: G2G')).toContainText('v3')
  await expect(page.getByText('does not say a geography')).toBeVisible()
  await page.getByRole('link', { name: 'Open its product page' }).click()
  await expect(page).toHaveURL(/\/portfolio\/g2g\?tab=icp/)
})
```
