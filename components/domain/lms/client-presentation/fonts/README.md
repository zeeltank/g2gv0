# Fonts for the client presentation (self-hosted)

Fraunces (roman + italic, variable weight and optical size) and Manrope (variable weight), Latin subset, as woff2.
Both are SIL Open Font License 1.1 fonts, from Google Fonts (fonts.google.com/specimen/Fraunces, /Manrope), downloaded 2026-11-23.
Self-hosted so the build and the visitor's browser make no request to Google (the build once depended on fetching them).
