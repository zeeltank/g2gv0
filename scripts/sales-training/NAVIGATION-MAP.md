# Interactive Sales Training: navigation map

Generated by `generator/build.js`. Slide numbers are the numbers in the .pptx.

## Structure

```
Home (1) -> How it works (2)
  -> Product hub (per product) -> 8 info slides (overview, modules(+details), problems, customers, benefits, proof, readiness, cannot-claim)
  -> Persona -> Decision 1 ... Decision 8 -> Outcome (Won | Won with concessions | Stalled | Lost)
```

## Branching rule (applies to every decision)

| Current lane | Best move | Partial move | Poor move |
|---|---|---|---|
| Strong (S) | next decision, Strong | next decision, Wavering | Recovery slide -> recover: next decision, Wavering / double down: Lost |
| Wavering (M) | next decision, Strong | next decision, Wavering | Lost (can replay) |

Last decision: S+best = **Won**; S+partial = **Won with concessions**; S+poor = recovery (recover = **Stalled**, else Lost); M+best = Won with concessions; M+partial = **Stalled**; M+poor = Lost.

## Limits of native PowerPoint navigation

- No variables without macros: confidence is encoded in which slide you are on (two parallel lanes), not a stored score.
- Hyperlinks work in Slide Show mode only.
- "Back" is PowerPoint's "last slide viewed" jump; pressing it twice returns you to where you were.
